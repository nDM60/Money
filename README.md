# Money

- **`money-pocket/`** — Money Pocket, the full-stack personal finance app (Next.js + PostgreSQL): accounts with real opening balances, transactions, budgets, savings, investments, reports, scheduled notifications, AI receipt scanner, Google Sheets sync and a multilingual AI assistant (EN / LO / TH / VI). See [`money-pocket/README.md`](money-pocket/README.md).
- Root files (`index.html`, `manifest.webmanifest`, icons) — the original static "My Money" dashboard for the LINE Money Bot / Google Sheets setup, left unchanged.
